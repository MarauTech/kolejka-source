# Współpraca i zgłoszenia

Błędy zgłaszaj przez formularz Issues. Podaj wersję aplikacji, Androida, kroki odtworzenia i oczekiwany rezultat. Przy problemie z danymi dodaj numer pociągu, stację i datę kursowania.

Nie umieszczaj kluczy API, danych logowania ani dokładnej lokalizacji. Usuń prywatne dane ze zrzutów i logów.

Przed pull requestem uruchom formatowanie, `flutter analyze` i `flutter test`. Zmiany widoków sprawdź na 320, 360, 384 i 411 px. Rozwijaj istniejące formattery i mapowanie stacji; nie traktuj identyfikatorów lub numerów sekwencji jak indeksów innych list.

Opis PR powinien zawierać problem, zakres zmiany i sposób weryfikacji. Nie dodawaj wygenerowanych plików kompilacji ani kluczy podpisu.
